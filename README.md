# Ship Control Lab — robust PID autotuning

Интерактивный исследовательский стенд для направления **27.03.04 «Управление в технических системах»**. Проект сопровождает статью для «Недели науки СПбГМТУ – 2026» и моделирует удержание курса судна по модели Номото первого порядка.

## Что нового в этой версии

Главная функция — **реальная автоматическая настройка ПИД-регулятора**. Кнопка `⚙ Подобрать Kp, Ki, Kd` запускает детерминированный многоуровневый pattern search и заново оценивает кандидатов на девяти сценариях:

- постоянное возмущение: **5°, 10°, 15°** в эквиваленте угла руля;
- номинальная модель: `K = 0.185 1/с`, `T = 107.3 с`;
- более маневренная модель: `K +10%`, `T −10%`;
- более инерционная модель: `K −10%`, `T +10%`.

Поиск выполняет **304 оценки** целевой функции и для параметров статьи находит:

- `Kp = 14`;
- `Ki = 0.1775 1/с`;
- `Kd = 206.25 с`.

Исходная ручная настройка: `Kp = 9`, `Ki = 0.08 1/с`, `Kd = 120 с`.

Комплексный критерий снижается с **0.7660 до 0.5071**, то есть примерно на **33.8%**.

## Быстрый запуск

Ничего устанавливать не требуется.

1. Распакуйте архив.
2. На Windows запустите `START_SIMULATOR.bat` или откройте `index.html`.
3. Нажмите **«⚙ Подобрать Kp, Ki, Kd»**.
4. Для опыта статьи используйте пресеты **«Ручной ПИД · 10°»** и **«Авто-ПИД · 10°»**.

Программа работает полностью локально и не требует интернета.

## Целевая функция автонастройки

Для каждого сценария рассчитывается безразмерный критерий, включающий:

- `30%` — интегральную абсолютную ошибку `IAE`;
- `20%` — время восстановления после постоянного возмущения;
- `15%` — максимальное отклонение курса;
- `10%` — среднеквадратичное использование руля;
- `15%` — время установления до появления возмущения;
- `10%` — перерегулирование.

Дополнительно применяется штраф при приближении к насыщению рулевого привода и добавляется `20%` от наихудшего сценария. Поэтому алгоритм не настраивается только под один удачный опыт.

## Результаты статьи

Для номинальной модели и возмущения `10°`:

| Показатель | Ручная настройка | Автонастройка |
|---|---:|---:|
| IAE, °·с | 260.14 | 176.39 |
| Макс. отклонение, ° | 1.081 | 0.619 |
| Возврат в ±0.5°, с | 114.6 | 57.4 |
| Установившаяся ошибка, ° | 0.038 | 0.003 |
| Время установления до возмущения, с | 57.5 | 24.9 |
| Макс. угол руля, ° | 27.87 | 31.50 |

Автонастройка уменьшает IAE примерно на `32%`, максимальное отклонение — примерно на `43%`, а время восстановления — примерно на `50%`. Цена улучшения — более активная работа рулевого привода.

## Что можно менять вручную

- начальный и заданный курс;
- момент ступени задания;
- П / ПИ / ПД / ПИД;
- `Kp`, `Ki`, `Kd`;
- параметры Номото `K`, `T`;
- постоянное, импульсное или синусоидальное возмущение;
- ограничение угла руля и скорость перекладки;
- длительность опыта и скорость анимации.

Программа строит графики курса, ошибки и руля, рассчитывает показатели качества и экспортирует CSV/PNG.

## Ограничения

Это учебно-исследовательская модель. Автонастройка оптимальна только в рамках выбранной модели Номото, заданных диапазонов параметров, ограничений привода и целевой функции. Найденные коэффициенты **не являются готовыми настройками для реального судна** без идентификации объекта и натурной верификации.
