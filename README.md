# Моделирование автоматического управления курсом судна

Репозиторий содержит воспроизводимый вычислительный эксперимент к студенческой статье
**«Моделирование системы автоматического управления курсом судна при внешних возмущениях»**
для «Недели науки СПбГМТУ – 2026».

## Что моделируется

Используется линейная **модель Номото первого порядка**:

`T · dr/dt + r = K · (δ + δв)`,  `dψ/dt = r`,

где `ψ` — курс судна, `r` — угловая скорость рыскания, `δ` — фактический угол руля,
а `δв` — эквивалентное постоянное внешнее возмущение.

Сравниваются два регулятора:

- **ПД:** `Kp = 9.0`, `Kd = 120 с`;
- **ПИД:** `Kp = 9.0`, `Ki = 0.08 с⁻¹`, `Kd = 120 с`.

В модели учтены ограничения рулевого привода:

- максимальный угол руля: **±35°**;
- максимальная скорость перекладки: **5°/с**;
- для ПИД используется anti-windup через условное интегрирование.

Параметры модели: `K = 0.185 с⁻¹`, `T = 107.3 с`, шаг интегрирования `0.05 с`.

## Сценарий основного эксперимента

1. 0–20 с: заданный курс 0°.
2. С 20 с: задание ступенчато меняется на 5°.
3. С 220 с: включается постоянное эквивалентное возмущение +10°.
4. Общая длительность: 600 с.
5. Отдельно ПИД-регулятор проверяется при возмущениях 5°, 10° и 15°.

> Важно: `δв` не является физическим углом ветра или течения. Это эквивалентное
> управляющее воздействие, компактно представляющее постоянный разворачивающий момент.

## Быстрый запуск

Требуется Python 3.10+.

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run_experiment.py
```

### Windows cmd

```cmd
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
python run_experiment.py
```

После запуска автоматически создаются/обновляются:

- `figures/course.png` — курс судна;
- `figures/error.png` — ошибка курса;
- `figures/rudder.png` — угол руля;
- `figures/scheme.png` — структурная схема;
- `results/main_metrics.csv` — сравнение ПД и ПИД;
- `results/pid_disturbance_series.csv` — серия опытов ПИД при 5°, 10°, 15°;
- `results/main_timeseries.csv` — полный временной ряд основного опыта.

## Ключевой воспроизводимый результат

При эквивалентном возмущении 10°:

| Показатель | ПД | ПИД |
|---|---:|---:|
| Время нарастания, с | 21.9 | 18.85 |
| Перерегулирование, ° | 0.02 | 0.51 |
| Время установления, с | 29.1 | 57.5 |
| Максимальное отклонение после возмущения, ° | 1.12 | 1.08 |
| Возврат в полосу ±0.5°, с | не достигается | 114.6 |
| Установившаяся ошибка, ° | 1.11 | 0.04 |
| Максимальный модуль угла руля, ° | 27.69 | 27.87 |

Главный вывод эксперимента: интегральная составляющая практически устраняет
установившуюся ошибку при длительно действующем постоянном возмущении, но увеличивает
длительность переходного процесса.

## Ограничения

Это **учебная вычислительная модель**, а не цифровой двойник конкретного судна.
Она не учитывает крен, поперечное движение, нелинейную гидродинамику, изменение скорости,
реальный спектр волнения и динамику ветра. Коэффициенты регулятора нельзя переносить
на реальное судно без идентификации объекта, моделирования более высокого уровня и испытаний.

## Как развивать работу

Следующие естественные шаги: модель Номото второго порядка, модель MMG, случайное волновое
возмущение, адаптивная настройка регулятора, идентификация параметров по экспериментальным
данным и сравнение с другими алгоритмами управления.


### Самый простой запуск в Windows

Можно просто дважды щёлкнуть `RUN_ME.bat`. Скрипт создаст виртуальное окружение, установит зависимости, выполнит эксперимент и запустит проверку воспроизводимости.

## Наглядная анимация движения судна

В репозитории есть отдельная визуализация, которая использует **тот же расчёт модели Номото**, что и статья.
Она показывает сверху условное движение судна, направление заданного и фактического курса, положение руля,
ошибку курса и момент включения внешнего возмущения.

### Самый простой запуск в Windows

Дважды щёлкнуть:

```text
RUN_VISUALIZATION.bat
```

Откроется интерактивное окно с анимацией ПИД-регулятора.

Чтобы автоматически создать GIF для презентации, GitHub или доклада:

```text
GENERATE_GIF.bat
```

или из терминала:

```bash
python visualize.py --save
```

Можно переключить регулятор:

```bash
python visualize.py --controller pd
python visualize.py --controller pid
```

Готовый GIF сохраняется в `visualization/ship_course_pid.gif`.

> Положение судна на плоскости является **условной кинематической визуализацией** и не используется при расчёте научных показателей. Научная часть по-прежнему основана на рассчитанных моделью Номото курсе, угловой скорости и угле руля.
